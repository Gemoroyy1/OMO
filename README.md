# ОМО

Учебный проект анализа данных.

## Лабораторные работы

- [Лабораторная №1. Классификация](Лаба1/README.md) — предобработка данных, KNN, SVM и дерево решений.
- [Отчёт лабораторной №1](Лаба1/reports/lab1/report.md).
- [Лабораторная №2. Кластеризация](Лаба2/README.md) — KMeans, DBSCAN, иерархическая кластеризация.
- [Отчёт лабораторной №2](Лаба2/reports/report.md).
- [Лабораторная №3. Регрессия](Лаба3/README.md) — линейная регрессия, LASSO и Ridge.
- [Отчёт лабораторной №3](Лаба3/reports/report.md).

Код и результаты работ находятся в папках `Лаба1`, `Лаба2` и `Лаба3`.
Общий исходный датасет находится в `data/raw/`, результат общей
предобработки — в `data/processed/`. Исходный CSV используется обеими работами.

Просмотр всех результатов и графиков:

```powershell
.\.venv\Scripts\python Лаба1/view_results.py
.\.venv\Scripts\python Лаба2/view_results.py
.\.venv\Scripts\python Лаба3/view_results.py
```
