# ОМО

Учебный проект анализа данных.

## Jupyter Notebook для защиты

- [Классификация](Лаба1/lab1.ipynb)
- [Кластеризация](Лаба2/lab2.ipynb)
- [Регрессия](Лаба3/lab3.ipynb)

В ноутбуках сохранены метрики и графики. Код вычислений приведён в ячейках.
По умолчанию используются сохранённые результаты; для повторного обучения
установите `REBUILD = True` и выполните Restart Kernel and Run All.
Запускайте с ядром Python окружения проекта, содержащего зависимости лабораторных.

```powershell
.\.venv\Scripts\python -m pip install -r requirements-notebooks.txt
.\.venv\Scripts\python -m notebook
```

## Лабораторные работы

- [Лабораторная №1. Классификация](Лаба1/README.md) — предобработка данных, KNN, SVM и дерево решений.
- [Отчёт лабораторной №1](Лаба1/reports/lab1/report.md).
- [Лабораторная №2. Кластеризация](Лаба2/README.md) — KMeans, DBSCAN, иерархическая кластеризация.
- [Отчёт лабораторной №2](Лаба2/reports/report.md).
- [Лабораторная №3. Регрессия](Лаба3/README.md) — линейная регрессия, LASSO и Ridge.
- [Отчёт лабораторной №3](Лаба3/reports/report.md).

Код и результаты работ находятся в папках `Лаба1`, `Лаба2` и `Лаба3`.
Общий исходный датасет находится в `data/raw/`, результат общей
предобработки — в `data/processed/`. Исходный CSV используется всеми тремя работами.
