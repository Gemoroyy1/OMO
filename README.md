# ОМО

Учебный проект анализа данных.

## Предварительная обработка

Код находится в `preprocessing.py`. Функция `main()` последовательно загружает
данные, строит графики, очищает таблицу и сохраняет результаты. Функция
`visualize()` отвечает за графики, а `save_figure()` — за сохранение изображений.
Конструкция `if __name__ == "__main__"` запускает обработку при запуске файла.

Установка и запуск в PowerShell (Python 3.12):

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python preprocessing.py
```

- `reports/figures/raw/` и `reports/figures/clean/`: гистограммы, ящики с усами
  по классам дефолта и диаграммы рассеяния до и после очистки.
- `data/processed/credit_risk_clean.csv`: строки без пропусков и дубликатов.
  Сначала `dropna()` удаляет строки с пропусками, затем `drop_duplicates()`
  удаляет повторяющиеся строки.
- `data/processed/credit_risk_normalized.csv`: числовые признаки в диапазоне
  от 0 до 1 по формуле `(x - min) / (max - min)`. Категории и `loan_status`
  не изменяются. Постоянный числовой признак получает значение 0.
- `data/processed/correlation.csv` и `reports/figures/correlation_matrix.png`:
  матрица корреляций Пирсона числовых столбцов, включая цель. Значения близкие
  к 1 или -1 означают сильную линейную связь, близкие к 0 — слабую.
- `data/processed/preprocessing_report.json`: число удалённых строк,
  пропуски, параметры нормализации и число случаев стажа больше возраста.

Признаки для графиков выбраны по смыслу задачи, их статистическая значимость
пока не проверялась. Категории не входят в матрицу Пирсона. Выбросы, включая
аномальный стаж, автоматически не удаляются. Они могут сжимать диапазон
обычных значений при нормализации. Исходный CSV не изменяется.

Эта нормализация предназначена для исследования данных. При обучении модели
нужно сначала разделить данные на обучающую и тестовую выборки и вычислить
минимумы и максимумы только по обучающей, чтобы избежать утечки данных.

## Набор данных

Выбран [Credit Risk Dataset](https://www.kaggle.com/datasets/laotse/credit-risk-dataset), автор Lao Tse, лицензия CC0: Public Domain. Согласно описанию Kaggle, данные имитируют сведения кредитного бюро.

Файл: `data/raw/credit_risk_dataset.csv`.

Проверка скачанного CSV (03.10.2026):

- 32 581 запись — больше требуемых 10 000.
- 12 столбцов: 11 признаков и целевой столбец `loan_status` — больше требуемых 10 признаков.
- Пропуски: `person_emp_length` — 895, `loan_int_rate` — 3 116. В остальных столбцах пустых значений нет.

Пропуски представлены пустыми ячейками. Исходный CSV сохранён без изменений. При загрузке через pandas пустые ячейки обычно становятся NaN — обозначением отсутствующего значения.

Цель возможной модели: предсказать дефолт по кредиту (`loan_status`: 0 — нет, 1 — да). Этот столбец следует отделить от признаков перед обучением.

### Значение столбцов

| Столбец | Значение |
| --- | --- |
| person_age | Возраст |
| person_income | Годовой доход |
| person_home_ownership | Тип владения жильём |
| person_emp_length | Стаж работы, годы |
| loan_intent | Назначение кредита |
| loan_grade | Категория кредита |
| loan_amnt | Сумма кредита |
| loan_int_rate | Процентная ставка |
| loan_status | Целевой показатель дефолта |
| loan_percent_income | Отношение суммы кредита к доходу |
| cb_person_default_on_file | История дефолтов |
| cb_person_cred_hist_length | Длительность кредитной истории |
