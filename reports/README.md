# Оформленные отчёты лабораторных работ

Редактируемые Word-версии лежат рядом с PDF под именем `report_gost.docx`.
Текст, таблицы и код редактируются непосредственно в Word; графики вставлены
изображениями. Заголовки используют стили Word, содержание и номера страниц —
поля. После открытия и после правок обновите поля: `Ctrl+A`, затем `F9`.
Титульные поля можно заполнить прямо в документе.

Повторная сборка Word-версий из сохранённых результатов:

```powershell
python reports/build_docx_reports.py
```

Повторная сборка перезаписывает DOCX, поэтому сохраните ручные правки отдельно.
Автоматическая визуальная проверка Word-версий в текущей среде недоступна:
пакетный renderer требует LibreOffice, который не установлен.

Готовые PDF находятся в `Лаба1/reports/report_gost.pdf`,
`Лаба2/reports/report_gost.pdf` и `Лаба3/reports/report_gost.pdf`.

Оформление: A4, Times New Roman 14 пт, полуторный интервал основного текста,
выравнивание по ширине, абзац 12,5 мм; поля слева 30 мм, справа 15 мм,
сверху и снизу 20 мм. Номера страниц расположены снизу по центру;
титульная страница учитывается, но номер на ней не печатается.
Содержание формируется автоматически с фактическими номерами страниц.
Рисунки и таблицы имеют подписи. Исходный код включён в приложения.

## Заполнение титульных листов

1. Впишите сведения в `reports/title_data.json`.
2. На Windows с установленными Times New Roman и Courier New выполните из корня:

```powershell
python -m pip install -r reports/requirements.txt
python reports/build_reports.py
```

Сборщик использует сохранённые результаты и графики лабораторных,
повторное обучение моделей не требуется. Текст описания дополняет
существующие Markdown-отчёты. Изменения результатов требуют повторной сборки PDF.

Скриншоты сняты с фактических локальных HTML-страниц результатов.
`capture_results.cjs` сохраняет их заново через Playwright и Edge;
путь к Playwright в скрипте задан для среды Codex на этом компьютере.
Для другого компьютера замените его на `require('playwright')` после установки
пакета Playwright. Код в приложениях переносится по ширине только для печати;
для запуска используйте исходные `.py` файлы лабораторных.
