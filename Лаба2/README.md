# Лабораторная №2. Кластеризация

Общий датасет находится в `data/raw/credit_risk_dataset.csv` в корне репозитория.
Скрипт самостоятельно удаляет пропуски и дубликаты, поэтому не требует запуска Лабы1.
Все команды ниже выполняются из корня проекта.

```powershell
.\.venv\Scripts\python -m pip install -r Лаба2/requirements.txt
.\.venv\Scripts\python Лаба2/view_results.py
```

Откроется страница с метриками, экспертной оценкой, профилями групп и графиками.
Готовую страницу `reports/results.html` можно открыть непосредственно в браузере.
Повторить вычисления: `python Лаба2/view_results.py --rebuild` тем же Python из .venv.
Только обучение: `.\.venv\Scripts\python Лаба2/clustering.py`.

## Методика

Все три модели используют одинаковую случайную выборку из 4000 очищенных строк
с seed=42. Это ограничивает квадратичные затраты иерархического метода и позволяет
честно сравнивать разбиения на одних объектах. Выводы относятся к этой выборке.
Цель `loan_status` исключена до преобразования признаков. Отдельной тестовой
выборки нет: это исследовательская кластеризация имеющихся объектов.

Числа стандартизируются, категории кодируются OneHotEncoder. Модели используют
евклидовы расстояния в полном пространстве из 26 признаков. Масштабирование,
категории и выбросы влияют на полученное разбиение. Аномалии не удаляются.

- KMeans: число кластеров 2–8, n_init=10, random_state=42.
- DBSCAN: eps=0.8/1/1.2/1.4/1.6/1.8/2/2.5/3, min_samples=3/5/10/25.
- Иерархическая кластеризация: 2–8 кластеров, linkage=ward/average.

Параметры выбираются по silhouette без использования реальных классов.
Для DBSCAN шум исключается из silhouette, требуется хотя бы 2 кластера
и coverage ≥ 0.5. Критерий выбора: silhouette − доля шума. Это явное
эвристическое правило; оно не гарантирует содержательных или сбалансированных групп.
Для вычисления silhouette используется максимум 1500 объектов с seed=42.

Сравнение с реальными классами: ARI, AMI, homogeneity, completeness и таблицы
численности классов в каждом кластере. Номера кластеров не являются классами 0/1.
Шум DBSCAN в этом сравнении учитывается как отдельная группа −1.

PCA используется только для рисунков. Дендрограмма строится отдельно для
150 объектов и не изображает все 4000 наблюдений. Экспертная оценка основана
на средних значениях признаков, типичных категориях, размерах групп и долях дефолтов.
