# Лабораторная №3. Регрессия

Прогноз непрерывной процентной ставки `loan_int_rate` на общем Credit Risk Dataset.
`loan_status` — результат кредита — исключён из признаков. Категория кредита
`loan_grade` используется как известный признак; это условие интерпретации результата.

Команды из корня проекта:

```powershell
.\.venv\Scripts\python -m pip install -r Лаба3/requirements.txt
.\.venv\Scripts\python Лаба3/view_results.py
```

Страница показывает метрики, параметры, графики предобработки, прогнозы,
остатки и коэффициенты. Открыть без Python: `Лаба3/reports/results.html`.
Пересчитать обработку и обучение:

```powershell
.\.venv\Scripts\python Лаба3/view_results.py --rebuild
```

Обучение без открытия браузера: `.\.venv\Scripts\python Лаба3/regression.py`.
Обновить отчёт/HTML без открытия браузера: `view_results.py --no-open` тем же Python.
Точные версии зависимостей: `requirements-lock.txt`.

## Структура и код

- `regression.py`: загрузка общей таблицы, удаление пропусков и дубликатов,
  разделение 80/20, стандартизация, обучение и подбор параметров.
- `view_results.py`: создание отчёта и HTML по сохранённым результатам.
- `processed/`: тренировочные и тестовые признаки после преобразования.
- `reports/`: метрики, параметры, коэффициенты, предсказания и 10 графиков.

`make_pipeline()` объединяет `ColumnTransformer` с регрессором. Числа
обрабатывает `StandardScaler`, категории — `OneHotEncoder(drop="first")`.
Средние и масштабы вычисляются только по обучающей части каждого фолда.
`GridSearchCV` выбирает alpha для LASSO и Ridge по RMSE пяти фолдов.
Линейная регрессия минимизирует сумму квадратов ошибок; LASSO добавляет
L1-штраф и может обнулять коэффициенты, Ridge — L2-штраф и сжимает их.
`evaluate()` вычисляет MAE, RMSE, R²; `save()` сохраняет рисунки.

Сначала исследуются гистограммы, диаграммы рассеяния и ящики с усами.
Графики `raw_*` относятся к полному исходному набору, `train_clean_*` —
к очищенной тренировочной части. Они показывают разные составы выборок,
поэтому различия обусловлены и очисткой, и разделением 80/20.
Признаки выбраны по смыслу задачи, формальная статистическая значимость не проверялась.
Графики исходного набора не используются для подбора параметров.

Метрики и графики прогнозов вычисляются на отдельном тесте. MAE и RMSE
измеряются в процентных пунктах, R² — безразмерная оценка объяснённой вариации.
Для сравнения сохранён baseline — средняя тренировочная ставка.
